# Tori Loukas: Personal Website

Personal portfolio built with [Quarto](https://quarto.org) and hosted on GitHub Pages.

- **Live site:** https://toriiloukas.github.io/my-website
- **Pages:** About · Projects · CV (downloadable PDF) · Contact
- **Theme:** custom SCSS (`styles.scss`) in cream and chocolate brown

## Build

```bash
quarto preview   # live preview
quarto render    # builds the static site into docs/
```

GitHub Pages serves the site from the `main` branch, `/docs` folder.
